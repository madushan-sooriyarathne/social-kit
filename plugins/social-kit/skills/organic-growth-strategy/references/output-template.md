# Output Template

Use this structure for the strategy deliverable. Keep sections tight; cut any that add nothing for this brand. Write concisely and directly.

```
# [Brand] Organic Growth Strategy: Instagram, Facebook, Threads

[Date] · Prepared for [brand or client]

## Summary
3-5 sentences: where the brand stands, the single biggest opportunity, and the
core plan (platform roles, cadence, format mix). State any assumptions made
about capacity or goals here.

## Current state
Short table per platform: followers, size tier, posting frequency, main formats,
notable strengths. Note anything that could not be verified.

## Biggest gaps (ranked)
3-5 gaps, each with the benchmark it misses and the expected impact of fixing it.

## Platform roles
One line each for Instagram, Facebook, Threads: role (growth engine, maintenance,
opportunistic) and why, given this audience.

## Content pillars
3-5 pillars. For each: what it covers, why it fits this audience, primary format.

## Weekly operating plan
Table: platform, format, posts per week, purpose. Include Stories cadence and the
reply routine. Keep it within the team's stated capacity.

## Format playbook for this brand
Brand-specific rules for Reels (length, hook, on-screen text, spoken keywords),
carousels (topics that earn saves), Stories (sequence shape, interactive element),
captions (keyword first line, CTA), Facebook and Threads adjustments.

## Collab plan
Target partner types (equal or larger reach), how to run creator-published Collab
posts, monthly target.

## First-month content calendar
12-20 concrete post ideas: week, platform, format, hook (first frame or slide),
pillar. Specific to this brand, not generic.

## KPIs and targets
Table: KPI, benchmark for this tier, current value if known, 90-day target.
Explain that posts are judged against the account's own median.

## What to stop doing
Brand-specific list drawn from the "what to avoid" evidence.

## Tests to run
2-4 experiments for thin-evidence areas or open questions (for example link in
comments vs image post on Facebook, Story sticker types, Lives).

## Caveats
Two or three sentences: correlational data, differing denominators, figures as
of the evidence date.

## Sources
Short list of the studies relied on.
```
